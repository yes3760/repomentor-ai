# Film Öneri Uygulaması

Kullanıcının beğendiği filmlere göre benzer filmler öneren bir Streamlit uygulaması.
Öneriler, film türleri ve puanlar üzerinden basit bir benzerlik skoru ile hesaplanır.

## Kurulum

```bash
pip install -r requirements.txt
```

## Çalıştırma

```bash
streamlit run src/app.py
```

Uygulama açıldığında listeden bir film seçin ve "Öner" butonuna basın.
